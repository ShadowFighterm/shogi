# 🀄 Shogi (Japanese Chess) in C++

A simple **Shogi (Japanese Chess)** game built in **C++** with a basic user interface.  
This project focuses on implementing the rules of Shogi and a minimal UI for board and piece movement.  

---

## 🚀 Features
- Standard **9x9 Shogi board**  
- All traditional Shogi pieces (King, Rook, Bishop, Gold General, Silver General, Knight, Lance, Pawn)  
- Legal move validation for each piece  
- Turn-based gameplay (Black vs White)  
- Piece drops (captured pieces can be reused)  
- Basic console / text-based UI for moves  

---

## 🔧 Prerequisites
Before running the program, make sure you have:

- **C++17 or later**  
- A C++ compiler: `g++` (Linux/MinGW) or MSVC (Windows)  
- **Git**
